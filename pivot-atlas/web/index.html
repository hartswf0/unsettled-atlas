    How it was made

    1. Sentinel-2 L2A scenes read directly from the open AWS COG archive (no STAC API), composited by orbit, 20 m analysis stack.
    2. Candidates: Hough circles on two channels (VIS+SWIR brightness, and SWIR/NIR, which stays low inside fallow disks).
    3. Confirmation by rim structure, not greenness; farm-lattice invariant admits faint circles and predicts empty sites; touching-not-overlapping suppression.
    4. Sub-pixel half-max circle fit; bare and non-circular objects (rock outcrops) rejected.
    5. Per-field polar unwrap gives planted sectors; nine March epochs give first-seen and abandonment.
    6. Assembler: hex lattice, CIELAB matching, chips rotated so planted wedges follow image edges, repetition penalty. Halftone dot size is each field's true radius on one shared scale. Gaps are measured desert sand.
